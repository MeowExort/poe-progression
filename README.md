# PoE Progression

Планировщик и трекер SSF-прогрессии для Path of Exile с оверлеем поверх игры.
Десктоп-приложение на Electron: читает лог игры `Client.txt` и показывает состояние в окне и в оверлее.

## Запуск

Нужен Node.js 22+.

```bash
npm install
```

```bash
npm run dev
```

## Сборка exe

```bash
npm run dist
```

В папке `release` появится `PoE-Progression-<версия>.exe` — один переносимый файл, его можно скопировать
на другой компьютер и запустить без установки Node.js. Рядом остаётся папка `win-unpacked` с тем же
приложением в распакованном виде. Файл не подписан, поэтому Windows при первом запуске покажет
предупреждение SmartScreen: «Подробнее» → «Выполнить в любом случае».

## Настройка

- Путь к `Client.txt` определяется автоматически (Steam-библиотеки на всех дисках); если не нашёлся — вкладка «Настройки».
- Игра должна быть в режиме **Windowed Fullscreen**: поверх эксклюзивного полноэкранного режима оверлей не рисуется.

## План

Во вкладке «План»: опросник → выбор стартового билда (или сразу импорт своего) → маршрут актов.
После импорта кода Path of Building в маршруте появляются шаги с гемами — у какого квеста взять
наградой и у кого купить именно твоему классу, — а рядом вкладки с гемами, деревьями и предметами билда.
Во вкладке «Предметы» для каждого уника указан источник (босс, механика, карты, Orb of Chance на базу),
а для редких предметов — что в них потребует работы: связи, влияния, fractured-моды.

## Sanctum

Вкладка «Sanctum» сама распознаёт забеги по логу игры: считает время каждой комнаты, этажа и забега,
отличает пройденные от проваленных и ведёт статистику за сессию и за всё время.

- **Лут** считается по снимкам инвентаря персонажа с сайта Path of Exile после смены зоны. Сайт показывает
  инвентарь только владельцу аккаунта, поэтому нужна cookie сессии (`POESESSID`): она хранится
  зашифрованной средствами операционной системы и отправляется только на pathofexile.com.
- **Цены** берутся с poe.ninja — по данным внутриигровой биржи валюты.
- **Реликвии** оцениваются автоматически поиском похожих лотов на официальном трейде: по тем же модам,
  а если таких мало — по самому дорогому моду. Оценка грубая: это цены выставленных лотов.
- **Отслеживаемая валюта** настраивается: список предметов, которые показываются на полоске и в статистике.
- **Полоска** появляется поверх игры на время забега: полученная валюта, 32 комнаты с временем каждой,
  время этажей, забега и сессии, число заходов. Она пропускает клики мыши в игру.

## Оверлей

Хоткей (по умолчанию `Shift+F`) показывает и прячет то, что сейчас уместно: вне Sanctum — боковую панель
с планом, во время забега — полоску. Боковую панель можно отключить совсем. Место и размер каждой
раскладки меняются в «Настройки → Оверлей»: в режиме настройки оверлей перетаскивается и растягивается мышью.

## Разработка

```bash
npm test
```

```bash
npm run typecheck
```

Структура:

- `data` — база знаний: карточки билдов (`builds.json`), способы добычи с цитатами из патчноутов (`methods.json`)
  и данные сторонних проектов в `vendor` (у каждого свой `SOURCE.md` с происхождением и лицензией):
  маршрут актов из exile-leveling (MIT), уники и базы из Path of Building (MIT), карты с PoEDB (CC BY-NC-SA 3.0),
  моды реликвий из Awakened PoE Trade (MIT).
- `scripts` — скрипты, которыми данные в `data/vendor` обновляются после патча.
- `src/core` — логика без привязки к Electron: разбор маршрута, отслеживание позиции, подбор билдов, импорт Path of Building.
- `src/main` — процесс Electron: окна, оверлей, чтение и разбор лога, состояние сессии и плана.
- `src/preload` — мост между окнами и главным процессом.
- `src/renderer` — интерфейс на React (главное окно и оверлей).
- `src/shared` — общие типы.
- `test` — тесты.

Данные приложения (настройки, план, история событий, зашифрованная cookie и кэш цен) лежат в `%APPDATA%\poe-progression`.
