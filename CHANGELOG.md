# Список изменений

Здесь описано, что меняется в каждой версии. Раздел версии попадает в её релиз на GitHub,
а оттуда — в окно обновления приложения.

## 0.2.0

Первая версия с автообновлением.

### Обновления

- Приложение само проверяет новые версии, скачивает их в фоне и показывает, что изменится.
- Обновление ставится по кнопке или при следующем закрытии приложения; во время забега в Sanctum не предлагается.
- Вместо переносимого файла теперь установщик: он ставит приложение в профиль пользователя, права администратора не нужны.

### Sanctum

- Забег продолжается после перезапуска приложения: пропущенные комнаты и их время берутся из лога игры, лут за время простоя считается одним чтением инвентаря.
- Забег, начатый при закрытом приложении, подхватывается; его лут считается с момента запуска.
- Реликвии оцениваются по трейду, у каждой есть ссылка на поиск, по которому вынесена оценка.
- Цена засчитывается, только если на трейде не меньше трёх похожих лотов; ценные моды (Quantity of Relics от 24%, 2 ревила, 2 выбора у торговца) оцениваются всегда.
- Забег можно удалить из истории (с подтверждением) — он перестаёт учитываться в статистике.
- Статистика «за всё время» учитывает валюту из забегов, записанных старыми версиями.

### Полоска

- Счётчик заходов стоит в две строки под таймером сессии, сферам и комнатам досталось больше места.
- Сферы и комнаты выровнены по центру высоты полоски.
